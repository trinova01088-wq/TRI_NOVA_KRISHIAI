
🌱 TRI_NOVA_KRISHIAI

AI Powered Smart Agriculture System

TRI_NOVA_KRISHIAI is an AI-based agriculture project designed to identify plant diseases using leaf images.

🎯 Project Objectives

- Plant disease detection
- Image-based disease identification
- AI-powered predictions
- User-friendly web application
- Support for 15 initial classes

🛠️ Technologies

- Python
- TensorFlow
- Streamlit
- Google Colab
- GitHub

📂 Project Files

- "app.py" – Web application
- "train.py" – Model training setup
- "requirements.txt" – Python dependencies
- "class_names.txt" – Initial class list

🚧 Project Status

Currently under development.

🌱 Future Goals

- Train the AI model
- Test prediction accuracy
- Build the Streamlit interface
- Deploy the application online
